# Dolina 960 — Resort & Hotel Landing Page 🏔️

Премиальный лендинг для горного отеля, выполненный с использованием SASS. Проект фокусируется на эстетике, типографике и интерактивности через современные слайдеры.

---

## 🛠 Технологический стек

* **HTML5:** Семантическая верстка, обеспечивающая правильную структуру документа.
* **SASS (SCSS):** Использование препроцессора для модульности стилей, работы с переменными и вложенностью.
* **CSS3:** Использование **Flexbox** для построения сеток и кастомные переходы (transitions).
* **Библиотеки:**
    * `Swiper.js` — современный слайдер для реализации галереи и презентации номеров.
* **Fonts:** Подключение шрифтов через Google Fonts.

---

## 🚀 Как запустить проект

Для корректной работы всех функций (особенно внешних скриптов и путей) рекомендуется использовать локальный сервер.

### Использование Live Server (рекомендуется):
1. Откройте папку проекта в **VS Code**.
2. Установите расширение **Live Server** (если еще не установлено).
3. Нажмите на кнопку **Go Live** в статус-баре (внизу справа) или кликните правой кнопкой мыши по `index.html` и выберите **"Open with Live Server"**.
4. Проект автоматически откроется в браузере по адресу `http://127.0.0.1:5500`.
